# 📊 Revenue vs Target

A Power BI dashboard that tracks monthly revenue against targets, broken down by product and sales manager. It includes automatic end-of-month projections and AI-powered product recommendations based on the purchase behavior of similar customers.

## 🎯 Key Features

- 📅 **Month-over-month** revenue vs target comparison
- 🧑‍💼 Performance breakdown by **product** and **sales manager**
- 🔮 **Automatic projections** to forecast whether targets will be reached by end of month
- 🤖 **Product recommendations** powered by a Python similarity engine, suggesting items based on the purchase patterns of similar clients

---

## ⚙️ Tech Stack

| Tool | Usage |
|------|-------|
| **Power BI** | Data modeling, DAX measures, report design |
| **Python** | Recommendation engine (customer similarity) |
| **Power Query** | Data cleaning and transformation |
| **SQL** | Data source and initial queries |

---

## 🚀 How to Use

1. Click the dashboard link above to access the online version
2. Use the **month filter** to navigate between periods
3. Use the **product and manager slicers** to drill down into specific segments
4. Check the **projection card** to see the end-of-month forecast
5. Browse the **recommendation panel** for product suggestions per client
